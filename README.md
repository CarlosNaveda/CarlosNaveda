### Candidate Analyzer
🔗 **Repositorio:** https://github.com/CarlosNaveda/Candidate_Analyzer  
Aplicación desarrollada durante las elecciones presidenciales del Perú 2026 que utiliza inteligencia artificial para analizar información pública de los candidatos y organizar los resultados automáticamente en Notion.  
Fue mi primer proyecto utilizando modelos de IA mediante APIs, integrando información de RSS Google con análisis estructurado y con ello facilitar una toma de decisión más informada.  

**Tecnologías:** Python · OpenAI API · Notion API · RSS · Prompt Engineering

### Fansubpy
🔗 **Repositorio:** https://github.com/CarlosNaveda/fansubpy  
Herramienta desarrollada en Python para automatizar gran parte del proceso de subtitulado de videos mediante inteligencia artificial. A partir del audio genera subtítulos que posteriormente pueden ajustarse manualmente y complementarse con efectos visuales, como karaoke.
Aunque el proceso aún requiere una revisión final para lograr la máxima precisión, reduce significativamente el tiempo necesario para producir subtítulos de alta calidad.  

**Tecnologías:** Python · IA · Whisper · FFmpeg

### Growe *(Repositorio privado)*
Growe es el sistema que utilizo para organizar prácticamente toda mi vida personal y profesional: finanzas, productividad, notas, salud y otros proyectos.
Nació con el objetivo de reemplazar los distintos sistemas que había construido previamente en Notion y, al mismo tiempo, explorar el desarrollo asistido por IA utilizando herramientas de programación agéntica.
